📊 Sales Performance Analysis Portfolio
Canaan Ed-Tech Internship (Weeks 1-4)

This repository contains a comprehensive data analytics project focused on cleaning, analyzing, and visualizing multi-year retail sales data to drive business decision-making.

🚀 Project Milestones
Week 1: Data Preprocessing – Standardized column naming conventions and cleaned null values to ensure data integrity.

Week 2: Exploratory Data Analysis (EDA) – Identified top product categories and conducted regional performance comparisons.

Week 3: Time-Series Analysis – Analyzed historical sales trends from 2015-2018 to identify seasonal growth cycles and Q4 peaks.

Week 4: Executive Reporting – Synthesized technical findings into a professional dashboard and business summary for stakeholders.

💡 Key Business Insights
Market Leader: The West region is the strongest market, contributing 31.4% of total sales.

Top Category: Technology is the highest-grossing product category.

Growth Strategy: Identified significant year-over-year growth with consistent revenue surges in the fourth quarter (Q4).

🛠️ Tech Stack
Language: Python

Libraries: Pandas (Data Manipulation), Matplotlib & Seaborn (Data Visualization)

Tools: Jupyter Notebook, VS Code, GitHub
